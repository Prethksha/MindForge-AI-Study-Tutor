# MindForge AI ⚡

An AI-powered Study Tutor built with Streamlit and Gemini AI.

## Features

* AI-powered concept explanations
* Study notes generation
* Interview preparation
* Revision summaries
* PDF export of notes
* Modern Streamlit UI

## Tech Stack

* Python
* Streamlit
* Google Gemini API
* ReportLab

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```
